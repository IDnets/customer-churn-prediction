# Customer Churn Prediction Model

This repository contains a machine learning pipeline to predict customer attrition using demographic and service usage data.

## Features & Methods
- **Data Preprocessing:** Handling missing values, feature scaling with `StandardScaler`, and categorical encoding.
- **Machine Learning Models:** Trained Logistic Regression and Random Forest Classifiers using `scikit-learn`.
- **Evaluation:** Model performance evaluated via Accuracy Score, Precision, Recall, and Confusion Matrix.

## Tools Used
- Python 3.x
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## How to Run
1. Clone the repository: `git clone https://github.com/your-username/customer-churn-prediction.git`
2. Install dependencies: `pip install pandas numpy scikit-learn matplotlib seaborn`
3. Run `churn_model.py` or open `churn_model.ipynb` in Jupyter Notebook.
